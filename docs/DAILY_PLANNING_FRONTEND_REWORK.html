02 · Acceptance

Definisi selesai yang bisa
dicek oleh tim, bukan asumsi.

Frontend quality gate

  • Language switcher berlaku di semua modul utama.
  • Locale bertahan setelah submit dan redirect.
  • Tidak ada translation key mentah.
  • Layout, table, form, badge, alert konsisten.
  • Responsive tanpa horizontal scroll.
  • Print label dan export tetap berfungsi.

Business flow gate

  • Arrival dapat dibuat dan diedit.
  • Receive membuat tag dan stok sesuai aturan.
  • QC dan putaway menghasilkan status benar.
  • Stock movement tercatat satu kali.
  • Material Request tertaut ke WO.
  • Production Issue mengikuti permission.

Alur UAT end-to-end

DEPARTURE / ARRIVAL
↓
RECEIVE + TAG   →   QC PASS   →   PUTAWAY
↓
WAREHOUSE STOCK   →   MATERIAL REQUEST   →   MATERIAL ISSUE
↓
PRODUCTION START

03 · Control plan

Risiko utama dan cara
menjaganya tetap terkendali.

RisikoDampak yang terlihatKontrol
Bahasa tidak berubahMenu berubah, tetapi isi halaman tetap bahasa lama.Audit hardcoded string dan uji setiap redirect pada ID / EN / KO.
Flow berhenti di supplyUser melihat tombol tetapi proses berikutnya tidak berjalan.Uji form dari browser dan cocokkan action dengan route serta permission.
Stok tercatat gandaSaldo inventory berbeda dari histori movement.Pastikan update stok hanya terjadi sekali pada tahap yang ditetapkan.
Permission tidak sinkronMenu terlihat, tetapi user menerima 403 atau tidak punya aksi.Uji menu dan route untuk setiap role, termasuk direct URL.
Regression lintas modulPerbaikan satu halaman merusak halaman lain.Gunakan checklist per modul dan review diff bertahap.

Deliverables

  • Shared frontend layout dan komponen visual.
  • Translation key ID / EN / KO yang konsisten.
  • Halaman receiving, warehouse, production yang tervalidasi.
  • Regression checklist dan bukti UAT.
  • Known issues dengan prioritas.
  • Dokumen handover untuk tim operasional.

Catatan eksekusi

Jangan mengejar perubahan visual tanpa mengunci alur bisnis. Setiap perubahan frontend harus diuji dari perspektif user: apa yang terlihat, apa yang bisa diklik, status apa yang berubah, dan apakah stok serta histori tetap benar.
