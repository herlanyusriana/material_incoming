# Daily Update — 2026-08-25

## Ringkasan

Hari ini dilakukan dua optimasi UI utama pada sistem:

1. **Modal Add/Edit BOM Line** disederhanakan — bagian utama hanya menampilkan field esensial, field tambahan dipindahkan ke toggle "Advanced Options".

## 1. Optimasi Modal BOM Line

**File:** `resources/views/planning/boms/index.blade.php`

### Sebelum
Modal menampilkan tiga section terpisah:
- Komponen RM
- Material (Size, Spec, Name, Special)
- Process & WIP (Line No, Process Name, Machine, WIP Part, WIP Qty, WIP UOM, dll)

### Sesudah
- Bagian utama hanya menampilkan **RM Part**, **Qty**, **UOM**, **Make/Buy**, dan **Policy Override**.
- Semua field lainnya (Material, Process, WIP) digabung ke dalam satu toggle **"Advanced Options"** yang default tertutup.
- Ukuran font, padding, dan spacing diperkecil untuk tampilan lebih ringkas.

### Detail Perubahan
- `showWip` → `showAdvanced` di Alpine.js data
- Toggle "Process & WIP" diganti menjadi "Advanced Options" yang mencakup Material + Process & WIP
- Reduksi padding dan ukuran font di seluruh modal

---

## 2. Optimasi Size Field di Part Master

**File:** `resources/views/parts/_form.blade.php`

### Sebelum
Size field menggunakan grid 4 kolom dengan input Thickness, Width, Length, dan checkbox Coil dalam layout yang cukup luas dengan padding besar dan font `text-sm`.

### Sesudah
- Layout diubah menjadi **flex row** dengan tiga input (Thick, Width, Length) dan checkbox Coil dalam satu baris.
- Font diperkecil dari `text-sm` menjadi `text-xs` untuk input dan label.
- Padding dan margin diperkecil.
- Preview format otomatis tetap dipertahankan di bawah.
- Informasi tersimpan di field `register_no` tetap dipertahankan.

### Screenshot konsep
```
Size*  [Thick] × [Width] × [Length] [✓ Coil]
       Format: 0.7 x 530 x C · Ceklis Coil = C di panjang · tersimpan di register_no
```
